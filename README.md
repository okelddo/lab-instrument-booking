# 實驗室儀器預約系統

純 HTML／CSS／JavaScript 的儀器週表預約工具，版面依實驗室現有週表（儀器 × 日期）設計。

倉庫：https://github.com/okelddo/lab-instrument-booking

## 功能

- **使用者名稱必填**：未填名稱無法完成預約。
- **時段必填**：需指定日期、開始與結束時間。
- **自動避讓衝突**：同一儀器、同一天，時段重疊即拒絕，並顯示既有預約者。
- **週表檢視**：與原本試算表相同的儀器列（QL C band、O band、1064 放大器等）。
- **點格子預約／點既有預約可修改或取消**。
- **範例資料**：首次開啟會載入圖中 9/17–9/24 的既有預約，亦可再按「載入範例週表」。
- **匯出／匯入 JSON**：方便把資料備份或搬到另一台電腦。

## 使用方式

1. 直接開啟 [`index.html`](index.html)，或啟用 GitHub Pages 後用網址分享。
2. 上方先填「使用者名稱」。
3. 點週表空白格的「＋ 預約此時段」，填開始／結束時間與備註後儲存。
4. 若該儀器該時段已有人預約，系統會擋下並提示衝突對象。

### 啟用 GitHub Pages（給大家用網址開啟）

1. 打開本倉庫 Settings → Pages
2. Source 選 **Deploy from a branch**
3. Branch 選 `main`、資料夾選 `/ (root)`
4. 儲存後約一分鐘可使用：

   `https://okelddo.github.io/lab-instrument-booking/`

## 資料存放說明

此版本是前端單頁，預約資料存在每位使用者瀏覽器的 `localStorage`。

- 同一台公用電腦、同一個瀏覽器：大家看到的是同一份表。
- 不同電腦：請用「匯出 JSON」再「匯入 JSON」同步，或之後再接上共用後端（Google Sheet／Firebase）。

## 衝突規則

```
同一儀器 AND 同一日期 AND 既有開始 < 新結束 AND 新開始 < 既有結束
→ 判定衝突，禁止寫入
```

例如 09:00–12:00 與 11:30–15:00 會衝突；09:00–12:00 與 12:00–18:00 不衝突。
